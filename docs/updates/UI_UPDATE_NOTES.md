## 変更点
1. 回答後は Enter で次の問題へ（長押しリピートは無視）。4択は数字キー 1〜4 でも選択可。
2. 記述回答は数字だけのテンキー入力。iOS のテンキーにはマイナスがないため、「西暦 / 紀元前」の切り替えで指定する。
3. 出題画面に章・テーマ・タグ・説明を表示。
   - 出来事→年号: 出題中は章・テーマ・タグ（説明は年号を含まない場合のみ）、回答後は説明も含めて全部表示。
   - 年号→出来事: 答えのヒントになるため、回答後に表示。
4. ヘッダーを廃止。中止ボタンは出題画面の左上（進捗バーの左）へ。クイズ中は下部ナビも隠す。
